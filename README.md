# Changed Reference Linker

Based on [Zotero Reference Linker](https://github.com/ottersem/zotero-reference-linker) by Seungmin Park (ottersem). This is an independent derivative.

## Features

- Detects bibliography sections and numeric, alphanumeric, and author-year references.
- Highlights reference text in the Zotero PDF reader, including cross-page entries.
- Only a matched entry with an available PDF attachment displays a clickable **↗ PDF** badge, which opens that PDF.
- Filters identifiable page headers, footers, and standalone page numbers.
- Shows scanned, matched, and ambiguous counts in the reader toolbar.


## Installation

Install the `.xpi` file from [GitHub Releases](https://github.com/gesongping/Changed-Reference-Linker/releases) using Zotero **Tools → Plugins → Install Plugin From File**, then restart Zotero if prompted. The manifest currently targets Zotero 10.0.x.
